# Changelog

## 1.0.0

- Versioned offline Windows x64 game and matching C11 source packages with SHA256 checksums and source/commit manifests.
- Source builds use a checked staging folder, preserve a previous successful build on compile/test failure, and include executable version metadata.
- Clear startup and invalid-command errors, a matching package launcher, and a complete first-play/build/upgrade guide.
- Existing 31-butterfly game modes, rules, controls and original artwork retained; real-timer native round checks added alongside the 360-round simulation suite.

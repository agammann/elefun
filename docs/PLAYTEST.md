# Check physical controls and sound

Use the actual Windows ZIP from the same versioned release and keep the version shown in the title. This short check supplements automated native rounds.

1. Choose **2 PLAYERS**, **Most butterflies**, **Gentle** and start a round. Listen for the countdown/start sound.
2. Move player one with mouse and left click while player two uses arrows and Ctrl. Both nets should move and scoop; scores increase only for actual catches.
3. Try player one D + Space together with player two Left + Ctrl. Both nets should move in opposite directions and scoop. If the keyboard cannot register all keys, use mouse and left click for player one.
4. Press M to mute, catch a butterfly, then press M and catch another. Check sound follows mute/unmute using the selected Windows output device.
5. Switch windows while holding controls. Return to Elefun: it should be paused, with inputs released. Press Enter to resume, then R to confirm a fresh countdown and zero scores.

Record the game version, Windows version, input arrangement, whether both players registered together and what was actually heard. One person can operate both sides to inspect hardware behavior; that observation is separate from a two-person usability playtest. A silent computer or limited keyboard does not prevent mouse-first play.
